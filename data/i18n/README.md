# 表示言語の辞書

- ファイル名が言語（`en` 英語 / `fr` フランス語 / `ko` 韓国語 / `zh` 中国語）。
- 中身は **「日本語の文」: 「その言語の文」** の一覧です。
- 日本語には辞書がありません（画面に書いてある日本語がそのまま出ます）。

## 直したいとき

その言語のファイルを開いて、右側の文を書き換えるだけです。コードは触りません。

```json
"話しかけてみる": "Talk to a place",
```

## 新しい文が日本語のまま出るとき

画面に新しい文を足すと、辞書に無い文はそのまま日本語で出ます（壊れません）。
訳したいときは、その日本語をそのまま鍵にして1行足してください。

```json
"新しく足した文": "The translation",
```

## 注意

- `{name}` `{n}` `{area}` は、アプリが数字や名前を差し込む場所です。**訳文にもそのまま残してください。**
- 鍵（左側）は、コードに書いてある日本語と1文字でも違うと当たりません。句読点や「　」もそのままコピーしてください。
- 案内の前に出る注意書きは、この辞書ではなく `data/notices.json` にあります。
